# 04 — مواصفات الـ Features

كل feature هنا مكتوبة كـ **مشكلة → الحل → معيار القبول**.

---

## F-01 · نظام التحكم في الإظهار والإخفاء ⭐

**المشكلة:** عايز تتحكم بدقة في اللي بيظهر — من غير ما تحذف محتوى، ومن غير ما تنسى نسخة مسرّبة في الـ RSS.

**الحل — 3 مستويات:**

| المستوى | الفلاج | النتيجة |
|---------|--------|---------|
| 1 | `draft: true` | ما بيتبنيش أصلاً في production. بيظهر في `npm run dev` بس، بشارة حمرا `DRAFT` فوق الصفحة |
| 2 | `unlisted: true` | الصفحة موجودة وشغالة باللينك المباشر، بس مش في الأرشيف ولا البحث ولا الـ RSS ولا الـ sitemap + `noindex`. **مثالي علشان تبعت مقال لعميل أو recruiter قبل النشر** |
| 3 | `hideFrom: ['home','rss','search',...]` | تحكم دقيق سطح-بسطح |

**آلية التنفيذ:** كل الصفحات بتقرا من `forSurface()` في `src/lib/content.ts` (شوف `02-architecture.md §2.5`). مفيش أي صفحة بتفلتر بنفسها.

**كمان — إخفاء أقسام كاملة من الموقع** عبر `src/config/site.ts`:
```ts
export const sections = {
  writeups: { enabled: true,  inNav: true  },
  notes:    { enabled: true,  inNav: true  },
  labs:     { enabled: true,  inNav: true  },
  uses:     { enabled: true,  inNav: false }, // شغال بس مش في القايمة
  hire:     { enabled: false, inNav: false }, // مطفي دلوقتي
};
```
لو `enabled: false` → الصفحة ما بتتبنيش والروابط ليها بتختفي تلقائياً. يعني تقدر تطفي "Hire me" في يوم وترجعه في يوم من غير ما تلمس كود.

**معيار القبول:**
- [ ] مقال `unlisted` مش موجود في `/rss.xml` ولا `/sitemap-index.xml` ولا نتايج Pagefind، وبيفتح باللينك.
- [ ] `npm run build` ما بيطلعش أي ملف لمقال `draft`.
- [ ] تحويل `sections.notes.enabled` لـ false ما بيكسرش الـ build (مفيش لينك ميت).

## F-02 · محرك الـ Writeups

**الحل:** قالب ثابت بيخلي كل مقال يشتغل كـ تقرير، مش مدونة:

```
01 The target      → إيه هو، ومين بناه (لو أنت، قول)
02 Recon           → إزاي رسمت سطح الهجوم
03 The bug         → الجذر التقني + CWE + OWASP
04 Exploitation    → PoC (sanitized) + الأثر الفعلي
05 Dead ends       → اللي جربته وما نفعش   ← ده اللي بيميّزك
06 The fix         → كود إصلاح حقيقي        ← ده اللي بيثبت إنك developer
07 What it teaches → درس معماري عام
```

مكوّنات مساندة: TOC لزج في الـ rail، وقت قراءة، شارة صعوبة، لينك للنسخة التانية باللغة، مقالات مرتبطة **بالـ CWE مش بالـ tags** (أدق بكتير)، وزرار "Copy as Markdown" (الناس بتحب تحفظ).

**معيار القبول:** أي writeup من غير `05` أو `06` ما ينشرش. حط الشرط ده في checklist النشر.

## F-03 · البحث والفلترة

- **Pagefind** بعد الـ build. index منفصل للعربي والإنجليزي أوتوماتيك عبر `<html lang>` — من غير كونفيج.
- **تصحيح (2026-09) — الفلاتر مسارات مبنية مسبقاً، مش query params.** الصيغة القديمة هنا كانت
  `/writeups?type=own-system&hasFix=true` بفلاتر تراكمية. **دي مستحيلة على `output: 'static'`:**
  `Astro.url.searchParams` بتبقى فاضية وقت البناء، فأي فلترة بتقراها في الـ frontmatter بتبقى كود
  ميّت — والصفحة بترجع كل النتايج. (نفس الباج ده كان موجود فعلاً في `src/pages/labs/index.astro`
  واتصلّح في المرحلة 4.) الفلترة التراكمية من غير JS محتاجة صفحة مبنية لكل توليفة — انفجار توافيقي.
- **الشكل المعتمد:** فلتر **ببُعد واحد**، كل قيمة ليها **مسار حقيقي مبني وقت البناء**:
  `/writeups/category/[category]` · `/writeups/type/[targetType]` · `/writeups/cwe/[cwe]` ·
  `/writeups/year/[year]` · `/writeups/severity/[severity]` · `/writeups/series/[series]`
  (وبالعربي تحت `/ar/`). لينكات عادية `<a>` — **صفر جافاسكريبت**، فبتشتغل والـ JS مطفي بحكم التصميم
  مش بحكم الاحتياط.
- **عتبة التوليد:** الصفحة ما تتولدش غير لما **عنصرين على الأقل** يطابقوا القيمة. القيمة اللي ليها
  عنصر واحد بتتعرض **نص عادي مش لينك** — عشان ما نطلّعش صفحات أرشيف رفيعة (thin) ولا لينك لصفحة
  فيها نتيجة واحدة. العتبة ثابت واحد مسمّى في `src/lib/content.ts`.
- صفحات الفلاتر `noindex` وبرّه الـ sitemap — دي أدوات تنقّل، مش محتوى للفهرسة.
- `Ctrl/⌘ + K` بيفتح الـ command palette، وبيحمّل Pagefind **عند الطلب بس** (مش وقت تحميل الصفحة)
  عشان ميزانية الـ 15KB جافاسكريبت على صفحة المقال تفضل سليمة.

**معيار القبول:** بحث "حقن" بيرجّع نتايج عربية بس، وبحث "injection" بيرجّع إنجليزية بس. صفحات
الفلاتر بتشتغل والجافاسكريبت مطفي تماماً (مفيش سكريبت أصلاً على الصفحة). وأي قيمة بعنصر واحد
مش بتطلّع مسار ولا لينك.

## F-04 · Projects كـ Case Studies

كل مشروع صفحة بالهيكل ده:
```
المشكلة (مين العميل وإيه اللي كان بيوجعه)
دوري بالظبط        ← إلزامي. لو شغل فريق، قول أنت عملت إيه بالظبط
المعمار            ← دياجرام بسيط
قرارات تقنية       ← 3 قرارات ولماذا، والبديل اللي رفضته
Security posture   ← auth model, authz, input validation, secrets, rate limiting
الأرقام            ← مستخدمين / سجلات / uptime — أرقام حقيقية بس
اللي كنت هعمله غير كده
```

قسم **"Security posture"** هو اللي بيربط البورتفوليو بالبلوج. وأقوى محتوى ممكن تعمله على الإطلاق: **security review لنظام أنت بنيته**، تنشره كـ writeup ولينك من صفحة المشروع. ده بيقول: "أنا بابني، وبعد كده برجع أهاجم شغلي، وبصلح."

## F-05 · Labs / CTF

جدول بيتولد من ملف YAML — مش صفحات:
```yaml
- platform: TryHackMe
  name: Cyber Security 101
  result: "Rank #3 Egypt · #138 Global"
  date: 2025-02
  proof: https://tryhackme.com/p/...      # لينك تحقق
  writeup: /writeups/...                   # لو فيه
```
فلاتر بالمنصة والسنة، وشارة "writeup ✓" للي ليها مقال. **أي سطر من غير `proof` ما يتحطش.**

## F-06 · Notes & ملخصات الكتب والمقالات

Stream واحد بأنواع: `TIL` · `note` · `book` · `paper`.
ملخص الكتاب/المقال ليه قالب خاص:
```
المرجع (اسم + مؤلف + رابط)
لمين الكتاب ده مفيد ولمين مش مفيد
3 أفكار غيّرت طريقة شغلي
اللي مش موافق عليه               ← ده اللي بيخلي الملخص رأي مش نسخ
إزاي طبقته فعلياً
```
**تحذير حقوق نشر:** ملخص = فهمك أنت بكلامك. **ما تنقلش فقرات من الكتاب**؛ اقتباس قصير جداً مع مرجع لما يكون ضروري بس.

## F-07 · Journey / Timeline

تايم لاين رأسي على الـ rail، كل محطة فيها: التاريخ · إيه اللي حصل · **إيه اللي اتعلمته فعلياً** · لينك إثبات.
الشهادات جوه التايم لاين مش في grid لوجوهات. الشهادة سطر في القصة، مش جايزة معلقة.

## F-09 · Hire / Contact (اختياري ومتحكم فيه)

`sections.hire.enabled` بيتحكم فيها. لما تشتغل: صفحة واحدة بتقول بوضوح إيه اللي بتقدمه (Web app security review / Full-stack build / Secure code review)، وإيه اللي مش بتقدمه، وإزاي تبدأ الشغل. من غير أسعار على الموقع في البداية.

## F-10 · RSS + Newsletter

- فيدين منفصلين: `/rss.xml` (EN) و `/rss-ar.xml` (AR) — الخلط بينهم بيخسّرك مشتركين.
- Newsletter (Buttondown أو Beehiiv): **ابدأه من اليوم الأول** حتى لو صفر مشتركين. الفورم يبقى في آخر المقال بس، بجملة محددة: "مقال جديد كل أسبوعين. مفيش سبام." — مفيش popups.

## F-11 · أثبت الحاجات (Proof layer)

قاعدة معمارية: **أي رقم أو إنجاز على الموقع لازم يكون معاه `proof` URL في الداتا**. لو مفيش لينك تحقق، الرقم ما يتعرضش.
ده اللي هيخلي الموقع يقول "TryHackMe #3 Egypt" من غير ما حد يشك ثانية.
