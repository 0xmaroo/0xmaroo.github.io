# 03 — نظام التصميم: "Blueprint & Breach"

## 3.0 الفكرة قبل أي لون

الكليشيه اللي بنهرب منه: خلفية سودا + أخضر Matrix + كود بيتساقط + صورة hoodie.
ده بيقول "أنا شكلي هاكر". إحنا عايزين الموقع يقول **"أنا فاهم السيستم"**.

**الاتجاه:** الموقع كأنه **مخطط هندسي (blueprint) اتكتب عليه بإيد مهاجم**.

طبقتين بصريتين، وكل طبقة ليها لون ودور:

| الطبقة | معناها | لونها | بتظهر فين |
|--------|--------|-------|-----------|
| **Blueprint** (البناء) | الدقة، الشبكة، القياسات، الـ labels | أزرق فولاذي بارد | الشبكة، الخطوط، الـ meta labels، أرقام الأقسام |
| **Breach** (الكسر) | التعليق، الشطب، العلامة، الاكتشاف | أصفر كبريتي (sulfur) | الـ accent، الهايلايت، `+` في الـ diff، الاقتباس المهم |
| **Stamp** (الحكم) | severity، الحالة | أحمر حبر مطفي | ختم الـ severity بس — **مش لون واجهة** |

الأصفر الكبريتي مقصود: ده لون قلم التعليق الفني/الهايلايتر، مش لون "هاكر". محدش تقريباً بيستخدمه في مواقع الأمن السيبراني، وده اللي هيخلّي الموقع **يتفتكر**.

## 3.1 Color tokens

```css
:root {
  /* Surfaces — أزرق-أسود، مش أسود صافي */
  --ink-900: #080A0F;   /* خلفية الصفحة */
  --ink-800: #0D1017;   /* سطح مرتفع / كروت */
  --ink-700: #141924;   /* سطح أعلى / hover */
  --ink-600: #1D2534;   /* حدود قوية */
  --line:    #1A202C;   /* حدود hairline */
  --grid:    #10141D;   /* خطوط شبكة البلوبرنت */

  /* Text */
  --text-hi:  #E8EBF0;
  --text:     #B6BDCA;
  --text-lo:  #6F7A8C;
  --text-dim: #4A5364;

  /* Blueprint (البناء) */
  --blue-400: #7FA6FF;
  --blue-500: #4E7CF6;
  --blue-900: #101A33;

  /* Breach (الكسر) — التوقيع */
  --sulfur-300: #F2E3A0;
  --sulfur-400: #E3C567;   /* الـ accent الأساسي */
  --sulfur-500: #C9A73E;
  --sulfur-900: #211C08;

  /* Stamp — severity فقط */
  --stamp-crit: #C6453C;
  --stamp-high: #C2683A;
  --stamp-med:  #A08A3C;
  --stamp-low:  #4E7CF6;
  --ok:         #3F9D6B;   /* patched / fixed */
}
```

**قواعد استخدام اللون (ملزمة):**
1. الأصفر الكبريتي ما يزيدش عن **~5%** من مساحة أي شاشة. لو زاد بيبقى موقع تحذيرات.
2. الأزرق للبنية والـ metadata. الأصفر للحاجة اللي عايزك تلاحظها بالظبط.
3. الأحمر **ممنوع** يستخدم لأي حاجة غير الـ severity والـ errors. مش زرار، مش hover، مش عنوان.
4. مفيش gradients على الخلفيات. مسموح gradient خطي واحد بس: خط الـ progress bar.
5. Light mode: **مرحلة 4، مش الأول**. الهوية دارك أصلاً — والـ light mode لازم يتعمل كويس أو ما يتعملش. (لما تعمله: `--ink-900: #F4F5F7` وبلوبرنت أزرق على ورق، مش عكس ألوان أعمى.)

## 3.2 Typography — الجزء اللي بيفرّق

**عائلة واحدة، 4 أدوار — IBM Plex.** السبب مش الشكل بس: Plex هي العائلة الوحيدة المفتوحة اللي فيها **Sans + Mono + Condensed + عربي مصمم أصلاً في نفس النظام** (IBM Plex Sans Arabic). يعني النسختين العربية والإنجليزية بيبقى ليهم نفس الصوت البصري بالظبط — وده أصعب مشكلة في المواقع ثنائية اللغة.

| الدور | الخط | الاستخدام |
|------|------|-----------|
| Display | **IBM Plex Mono 600/700**, uppercase, `letter-spacing: -0.02em` | العناوين الكبيرة. استخدام mono في حجم display هو "الحركة" — بيدي إحساس آلة/طرفية من غير كليشيه |
| Body EN | IBM Plex Sans 400/500 | نص المقال |
| Body AR | **IBM Plex Sans Arabic** 400/500/600 | نص المقال العربي |
| Utility | IBM Plex Sans Condensed 500, uppercase, `+0.08em` | الـ labels والـ eyebrows والـ metadata |
| Code | IBM Plex Mono 400 | الكود والـ payloads |

**بديل لو عايز شخصية أقوى في العناوين:** `Chivo Mono` أو `Martian Mono` للـ display بس، مع الإبقاء على Plex لباقي الحاجات. **ما تستخدمش** Inter كـ display (ده بالظبط شكل كل بورتفوليو تاني).

**مقياس الخط (fluid):**
```css
--step--1: clamp(0.83rem, 0.8rem + 0.15vw, 0.9rem);
--step-0:  clamp(1rem,   0.96rem + 0.2vw, 1.08rem);
--step-1:  clamp(1.25rem,1.15rem + 0.5vw, 1.5rem);
--step-2:  clamp(1.6rem, 1.4rem + 1vw,   2.2rem);
--step-3:  clamp(2.1rem, 1.7rem + 2vw,   3.2rem);
--step-4:  clamp(2.8rem, 2rem + 4vw,     5rem);   /* الـ hero */
```
- طول السطر: **68 حرف** إنجليزي / **72 حرف** عربي.
- `line-height`: 1.65 للإنجليزي، **1.85 للعربي** (العربي محتاج مساحة أكتر بسبب النقط والحركات).

**5 قواعد للعربي مش موجودة في أي design system عام — والتزم بيها:**
1. **ممنوع `letter-spacing` على العربي نهائياً.** بيكسر اتصال الحروف. (`[lang="ar"] * { letter-spacing: 0 !important }`)
2. **ممنوع `text-transform: uppercase`** — مفيش حروف كابيتال في العربي، والقاعدة دي بتضرب في الـ labels لو مش منتبه.
3. الوزن الخفيف (300) بيبان باهت جداً في العربي على خلفية دارك → أقل وزن **400**، والـ body يفضّل **450–500**.
4. الأرقام: استخدم **الأرقام العربية الغربية (1234)** مش الهندية (١٢٣٤) في السياق التقني — لأن الـ CVE والـ CWE والبورتات بتتكتب كده.
5. الكود والـ terminal **دايماً `dir="ltr"`** حتى داخل صفحة عربية. غير كده الـ output بيتقلب ويبقى غلط تقنياً.

## 3.3 الشبكة والـ Layout

الأساس: **12 عمود، عرض محتوى 1180px، gutter 24px**.
بس القراءة مش بتستخدم الـ 12 عمود:

```
┌──────────────────────────────────────────────────────────┐
│  RAIL   │        CONTENT (7 cols)        │  MARGIN (3)   │
│  (1)    │                                │               │
│  ruler  │  النص                          │  ملاحظات      │
│  index  │  الكود                         │  جانبية       │
│  §01    │  الصور                         │  payloads     │
│  §02    │                                │  refs         │
└──────────────────────────────────────────────────────────┘
```

- **الـ Rail (اليسار في EN / اليمين في AR):** شريط رفيع فيه رقم القسم + مؤشر تقدّم شكله **مسطرة قياس** (dimension line زي البلوبرنت)، مش progress bar عادي.
- **الهامش (Margin notes):** ده مكان الملاحظات الجانبية والـ payloads والمراجع. ده اللي بيدّي إحساس "دفتر معمل" بدل "بلوج".
- على الموبايل: الـ rail بيبقى خط أفقي رفيع تحت الهيدر، والهوامش بتنزل داخل النص كـ blocks مميزة.
- **Logical properties في كل حتة:** `margin-inline-start` مش `margin-left`. `padding-block` مش `padding-top`. كده الـ RTL بيشتغل من غير stylesheet تاني. أي `left/right` في الكود = bug.

## 3.4 التوقيع البصري (Signature) — الـ Diff Hero

ده اللي الناس هتفتكره. الـ hero مش جملة تعريف — ده **diff حقيقي**:

```
  ~/identity.txt
- I build systems that work.
+ I break systems that work.
```

- السطر الأحمر/المشطوب بلون `--text-lo` مع `-` أزرق، والسطر `+` بلون `--sulfur-400`.
- عند التحميل: السطر الأول يتكتب، يتشطب بخط رفيع، وبعدين السطر التاني يظهر. **مرة واحدة بس** (يتخزن في `sessionStorage`)، ومدة كلها **أقل من 1.2 ثانية**، ومحترمة `prefers-reduced-motion` (في الحالة دي بيظهروا الاتنين فوراً).
- تحت الـ diff مباشرة: 3 أرقام **حقيقية** بس (مثلاً: `3 production systems` · `#3 TryHackMe EG` · `6th CAT Reloaded CTF`) — بخط Condensed صغير، من غير كروت ولا أيقونات.

**ليه ده شغال:** الـ diff هو أكتر artifact مألوف لأي developer وأي security engineer. هو بيقول الـ positioning بتاعك بلغة الجمهور نفسه، من غير ما تكتب paragraph عن نفسك.

## 3.5 المكوّنات الأساسية

**Case File Card** (لكل writeup) — مش card عادي:
```
┌────────────────────────────────────────────┐
│ CASE 014 · WEB          ▚ PATCHED          │  ← رقم + تصنيف + ختم الحالة
├────────────────────────────────────────────┤
│ The invoice endpoint that trusted a number │  ← عنوان (mono, display)
│                                            │
│ CWE-639 · A01:2021 · own-system            │  ← metadata بلون blueprint
│ 8 min · has fix ✓                          │
└────────────────────────────────────────────┘
```
الختم (`PATCHED` / `LAB ONLY` / `DISCLOSED`) شكله ختم حبر مايل شوية (`rotate(-3deg)`) بحواف مش مثالية. تفصيلة صغيرة بس هي اللي بتدي إحساس "ملف قضية".

**مكونات جوه المقال (MDX):**
- `<Payload lang="http">` — بلوك بخلفية `--ink-800` وحدود صفراء، وزرار نسخ، وشارة "sanitized" لو الـ payload متعدّل.
- `<FixDiff>` — قبل/بعد للكود بألوان الـ diff. **ده أهم مكون في الموقع كله** — هو اللي بيثبت إنك developer.
- `<DeadEnd>` — بلوك مطفي بلون `--text-lo` لتوثيق المحاولات الفاشلة.
- `<Callout type="warn|note|legal">` — الـ legal بيتحط في أي writeup على نظام حقيقي.
- `<Terminal>` — بلوك طرفية `dir="ltr"` دايماً، بدون animation.

**Command Palette (`Ctrl/⌘ + K`):** بحث Pagefind + تنقّل + تبديل لغة + تبديل ثيم. لمسة صغيرة بتخلي الزائر التقني يقول "الشخص ده بيهتم".

## 3.6 الحركة (Motion)

الفلسفة: **الحركة توضّح، ما تزوّقش.** مسموح 4 حاجات بس:

| الحركة | المدة | الغرض |
|--------|------|-------|
| Diff hero (مرة/جلسة) | ≤1200ms | تقديم الـ positioning |
| Reveal عند الاسكرول (opacity + 8px) | 320ms | تسلسل القراءة |
| Hover على الكروت: خط الحد بيتحول أصفر + الرقم بيتحرك 2px | 160ms | feedback |
| مؤشر التقدم في الـ rail | مستمر | مكانك في المقال |

**ممنوع:** parallax، كود بيتساقط، جسيمات، cursor مخصص، smooth-scroll يدوي، أي حاجة بتتحرك لوحدها وأنت بتقرا.
```css
@media (prefers-reduced-motion: reduce) {
  *,*::before,*::after { animation-duration:.01ms!important; transition-duration:.01ms!important }
}
```

## 3.7 أرضية الجودة

- Focus مرئي على كل عنصر تفاعلي: `outline: 2px solid var(--sulfur-400); outline-offset: 3px`.
- تباين: النص الأساسي ≥ 7:1 على الخلفية (AAA)، والـ `--text-lo` ≥ 4.5:1.
- أهداف اللمس ≥ 44×44px.
- Skip link + landmarks (`<main>`, `<nav>`, `<article>`) + ترتيب عناوين سليم (h1 واحد).
- الخطوط: **self-hosted** بصيغة woff2 مع `font-display: swap` وsubset للعربي والإنجليزي. (مش Google Fonts CDN — أسرع + خصوصية + متسق مع الـ CSP بتاعتنا.)
